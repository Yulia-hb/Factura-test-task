# Endless Runner Shooter (Vehicle-based)

Dynamic 3D arcade game developed in Unity where the player controls a vehicle, shoots enemies, and navigates an endless track.

## 🛠 Tech Stack & Architecture
* **Engine:** Unity (3D)
* **Language:** C#
* **Architecture:** Designed with **SOLID principles** for scalability and clean code separation.
* **Optimization:** Implemented **Object Pooling** patterns for bullet and enemy spawning to maintain high FPS and optimize memory consumption.

## 🎯 Implemented Features
* **Core Gameplay Loop:** Smooth progression, continuous track generation, and scoring systems.
* **Vehicle Controller:** Custom movement physics and handling logic.
* **Combat System:** Raycast and projectile-based weapon mechanics.
* **Enemy AI:** Behavior logic for enemy spawning, tracking, and engagement.
